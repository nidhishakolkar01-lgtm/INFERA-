## ⚡ Quick Start
To launch the application locally:

### Terminal 1: Backend
```bash
cd backend
npm run dev
```
Backend runs on `http://localhost:5000`.

### Terminal 2: Frontend
```bash
cd frontend
npm run dev
```
Frontend runs on `http://localhost:3000`.

---

## 🧪 Run Automated Security Test Suite
```bash
cd backend
node test-api.js
```
Runs 8 automated security verification tests verifying zero-trust denial, financial threshold holds, SQL injection blocking, cryptographic ledger tamper detection, separation of duties, and payload mutation guards.
